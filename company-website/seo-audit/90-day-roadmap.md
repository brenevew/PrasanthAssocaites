# 90-day roadmap (from 2026-11-13)

Rankings and lead growth are judged over the following reporting periods. Nothing here is reported as achieved on the day of deployment.

## Days 0–14: foundations

| Task | Owner | Measure |
|---|---|---|
| Deploy the `local-maps-seo` branch; request indexing for both location pages and home; resubmit the sitemap | Website / owner | URL Inspection shows the new crawl date |
| Apply the approved Google listing updates (category, services, descriptions, tagged website links, Tamil name) | Owner | Changes visible on both listings |
| Start review requests and reply to all existing reviews | Owner | New reviews per office per week |
| Set up GA4 key events, dimension and explorations | Owner (GA4 access) | `gbp_coimbatore` / `gbp_gudalur` sessions appear |
| Run the grid baseline (`analytics/maps-ranking-baseline.md`) | Owner / agency with a tool | Baseline file saved |
| Rich Results Test on both location pages | Owner | No errors |

## Days 15–45: presence and consistency

| Task | Owner | Measure |
|---|---|---|
| Bing Places and Bing Webmaster Tools; IndexNow after each deploy | Owner | Bing listing correct; Bing shows indexed pages |
| Justdial, Sulekha, IndiaMART for both offices with identical name, address, phone | Owner | Listings live and consistent |
| Weekly listing posts and monthly photos | Owner | Posts per month |
| Supply rates and project details; add them to the site | Owner, then website | Cost FAQs with figures; fuller project pages |
| Day-30 review: Search Console impressions for each location page; GA4 listing sessions and leads | Website | Report vs baseline |

## Days 46–90: authority and measurement

| Task | Owner | Measure |
|---|---|---|
| Ask suppliers, project clients and local associations for links to the relevant project or location page | Owner | New referring sites |
| Second grid run (around day 45) and third (around day 90) | Owner / agency | Top-3 share and average rank per keyword vs baseline |
| Day-60 and day-90 reviews: Search Console queries in positions 4–20 for each location page; strengthen the matching content | Website | Position changes for those queries |
| Lead-quality columns in the enquiry sheet | Owner | Qualified enquiries and projects by office |

## Targets (objectives, not promises)

| Metric | Baseline | Day-90 objective |
|---|---|---|
| Coimbatore Google reviews | 32 | 40+ |
| Gudalur Google reviews | 45, featured ones ~5 years old | 50+, with reviews from the last month |
| Owner replies to reviews | Gudalur: none visible | All reviews replied to |
| Grid top-3 share, "building contractors in gudalur" | Not yet measured | Higher than the first run |
| Grid presence, "building contractors in coimbatore" | Not yet measured | Present at more points than the first run |
| Leads tagged `gbp_coimbatore` / `gbp_gudalur` | Not yet measured | Tracked monthly |
